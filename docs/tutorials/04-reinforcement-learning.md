# 4. 강화학습: 관측에서 행동과 보상까지

**완료 기준:** 전투기 상태가 관측 벡터가 되는 방식과 정책 행동·보상의 역할을 설명하고, 새 기동 정책을 학습해 리플레이에서 살펴봅니다.

## 강화학습의 작은 고리

한 스텝은 다음 순서로 이해할 수 있습니다.

1. 환경이 현재 교전 상태를 만들고 정책에 제공합니다.
2. 정책이 이산 행동 하나를 선택합니다.
3. 환경이 항공기·무장 상태를 갱신합니다.
4. 정책은 보상과 다음 관측을 받습니다.
5. PPO가 여러 번의 경험으로 정책을 업데이트합니다.

이 프로젝트의 관측은 `swarm_aircombat/rl/state.py`에서 25개 채널로 변환됩니다.
각 채널은 배정 표적의 거리·각도, 내 기체 상태와 전투 상황 등을 정규화합니다.
표적 기준 상대값을 사용하면 팀 규모가 달라도 정책 입력의 의미를 유지하기 쉽습니다.

행동은 `SwarmPursuitEnv`의 `Discrete(27)`입니다.
세 방향 전환 × 세 속도 변경 × 세 고도 변경의 조합입니다.
정확한 값과 인코딩 순서는 `swarm_aircombat/envs/swarm_pursuit.py`의 `HEADINGS`, `SPEEDS`, `ALTITUDES`, `decode()`에서 확인하세요.
정책이 직접 플랩·조종면을 제어하는 것이 아니라, 목표 heading/speed/altitude 명령을 선택합니다.

## 보상은 무엇을 가르치나

`swarm_aircombat/rl/reward.py`는 다음 신호를 조합합니다.

- shaping: 표적까지 가까워지고 추격 기하가 좋아지는 변화
- 피해와 격추: 적에게 준 피해는 보상, 받은 피해와 격추는 비용
- WEZ: 발사 가능 영역에 들어간 상태에 대한 작은 보상
- 충돌과 시간: 아군 근접 충돌과 에피소드 지연을 억제
- 종료 결과: 팀 승리/패배 보상

Shaping은 학습을 돕기 위한 단계별 신호입니다. 그 자체가 임무 목표인 승리율과 같지는 않습니다.
보상 가중치를 바꿀 때는 학습 곡선만 보지 말고 held-out 시드에서 승률·격추·충돌 등 여러 결과를 측정합니다.

## PPO 학습 실행

`stable-baselines3`, `torch`는 학습 선택 의존성입니다. 설치 전에는:

```bash
python -m pip install -e ".[train]"
```

간단한 학습 명령:

```bash
python scripts/train.py --red-behavior mixed --n-blue 4 --n-red 2 \
  --steps 100000 --worlds 4 --seed 0 --name tutorial
```

`--steps`는 에이전트 샘플 수입니다. 병렬 세계 수를 늘리면 각 환경의 물리 시간이 빠르게 진행되는 것이 아니라 샘플을 병렬 수집합니다.
결과는 `runs/tutorial/s0/` 아래에 저장됩니다.

| 파일 | 쓰임 |
|---|---|
| `best.zip` | 검증 점수가 가장 좋았던 모델 |
| `last.zip` | 학습 종료 시점 모델 |
| `progress.csv` | 검증 시점별 측정치 |
| `result.json` | 실행 인자와 최종 요약 |

학습이 끝났다고 성능이 좋아졌다는 뜻은 아닙니다. 별도의 시드·상대 정책에서 평가하세요.

```bash
python scripts/compare.py --red-behavior mixed \
  --policies lead runs/tutorial/s0/best.zip --episodes 30
```

!!! warning "구형 체크포인트 주의"
    저장소의 `models/pursuit_mixed.zip`은 이전 `Discrete(9)` 행동 공간에서 학습된 모델입니다. 현재 정책 인터페이스는 `Discrete(27)`이므로 호환 오류를 내며, 예전 가중치를 새 행동으로 조용히 해석하지 않습니다. 이 튜토리얼에서는 `best.zip`을 새로 학습합니다.

## 규칙·BT와 RL의 차이

규칙 기반 파일럿은 사람이 작성한 코드로 행동을 결정합니다. BT는 그런 조건과 행동의
우선순위를 트리 구조로 표현합니다. PPO는 관측과 보상을 통해 정책 파라미터를
학습합니다. 셋은 전투기 행동을 만드는 서로 다른 방법이며, 이 프로젝트의 BT는
자동 학습되지 않습니다.

N:M 군집 트리에서는 경계 복귀·아군 분리 같은 분기를 먼저 처리한 뒤, 상황에 따라
선택된 Brain에 추격 기동을 맡깁니다. 따라서 리플레이에서 BT의 분기와 PPO의 행동을
구분해 관찰할 수 있습니다.

## 실습

1. `state.py`에서 `range_near`가 왜 거리의 지수 변환을 사용하는지 설명합니다.
2. `reward.py`에서 피해를 입지 않고 빙빙 도는 행동이 어떻게 평가되는지 추적합니다.
3. 작은 `--steps`로 학습을 실행하고 `progress.csv`를 확인합니다.
4. 같은 모델을 `lead`와 여러 시드에서 비교합니다. 승률이 포화되면 격추·충돌·시간 같은 다른 지표를 봅니다.
